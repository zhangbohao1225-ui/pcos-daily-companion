# SUTA 完整版微信小程序

本目录为未隐藏功能的完整版源码，包含 18 个页面和 5 个底部导航。仓库原有的网页项目保留在原位置。

## 功能

- 首页、每日打卡、饮食记录、经期记录、健康科普
- AI 健康顾问
- 论坛图文帖子、分类、点赞、评论、帖子编辑和删除
- 同伴主页、关注与粉丝列表
- 私信会话、未读计数与举报入口
- 组队打卡与队友鼓励
- 个人资料、头像、健康目标、主题、反馈与协议
- 钱包和 SUTA Pro 页面（实际充值及会员支付尚未接入）

“完整版”表示所有已有功能入口均保留，不表示支付、云端部署或平台资质已经完成。

## 在微信开发者工具中打开

1. 下载或克隆本仓库。
2. 在微信开发者工具选择“导入项目”，目录选择本目录 `miniapp`。
3. 检查 `project.config.json` 中的 AppID 和 `app.js` 中的 CloudBase 环境，使用有权限的微信开发者账号。
4. 按 [云开发部署说明](CLOUDBASE-DEPLOY.md) 建立集合和索引，分别部署 `forumHub`、`forumPostManager`、`toggleForumLike`、`teamHub`、`socialHub`，选择“上传并部署：云端安装依赖”。
5. 确认云端模型已开通，并验证个人资料、发帖、私信、组队等功能后再使用体验版。

原仓库根目录的 package.json 对应网页项目；打开本小程序不需要先启动网页服务。此目录不包含本机缓存、真实用户导出数据或开发者私有配置文件。

上传前已做 JavaScript 语法、JSON、页面文件、事件处理函数和注册路由检查。尚未在本次上传中执行云端部署、真实支付、微信审核提交或真机端到端验证。
